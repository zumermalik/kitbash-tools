# Kitbash Decisions

This file records durable product and technical decisions.

## 001. Build One Suite, Not Separate Apps

Decision: Kitbash will be one umbrella product with individual tool pages.

Reason: every tool can rank independently while contributing to one recognizable brand system.

## 002. Make Typewriter Invoice The Flagship

Decision: the typewriter invoice generator is the first signature tool.

Reason: it is visually distinctive, useful, shareable, and establishes the paper/receipt/monospace output language for the rest of the suite.

## 003. Start Without AI

Decision: the MVP will not depend on AI.

Reason: the first version should be fast, cheap to run, easy to ship, and useful without complex infrastructure.

## 004. Browser-First Processing

Decision: user files should be processed locally in the browser wherever practical.

Reason: this improves privacy, reduces server cost, and makes the tools feel immediate.

## 005. Orange-Based But Not One-Note

Decision: every tool can have a distinct theme, but all themes should live in shades and tints of orange.

Reason: this creates brand cohesion while preserving variety across the suite.

## 006. Use Free Commercially Usable Fonts

Decision: typography should use free and commercially usable fonts such as Instrument Serif, Cormorant Garamond, Inter, Source Sans 3, IBM Plex Mono, or JetBrains Mono.

Reason: the product needs a strong visual identity without licensing friction.

## 007. Tool UI Comes Before SEO Copy

Decision: tool pages should put the working utility before long explanatory content.

Reason: visitors arrive with intent. The page should satisfy that intent immediately, then support SEO below the tool.
