# Kitbash

Kitbash is a boxy, editorial design-tool suite built around small, useful web utilities. Each tool is a standalone search-friendly page, but the shared visual system is the real brand: orange-tinted themes, classic serif typography, monospace output panels, hairline borders, and tactile export surfaces.

The flagship feature is a typewriter invoice generator: users enter line items and receive a printable invoice typed onto a Japanese notebook-grid inspired page, with a subtle paper texture, monospace type, and a polished PDF export.

## Core Idea

Kitbash works as a mega tool rather than a set of disconnected apps. Every page solves one clear problem:

- remove a background
- compress an image
- generate a color palette
- check contrast
- generate a QR code
- create a favicon set
- format JSON
- preview metadata
- make a beautiful invoice

The business logic is simple: each utility can rank for its own intent, while the product experience keeps users moving through the wider suite.

## Brand Direction

- Name: Kitbash
- Mood: classic, useful, print-like, warm, precise
- Shape language: boxy, square, hairline bordered
- Color family: shades and tints of orange, supported by cream, ink, rust, amber, clay, and charcoal
- Typography: free-to-use serif display face with long serifs, plus a readable monospace for generated outputs
- Signature motif: every result area feels like a receipt, notebook sheet, paper slip, or code label
