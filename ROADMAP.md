# Kitbash Roadmap

## Phase 0: Product Definition

- Create core documentation.
- Define MVP scope.
- Define visual system.
- Define tool catalog.
- Choose technical stack.
- Create initial tool registry model.

## Phase 1: Foundation

- Build homepage.
- Build shared app shell.
- Build tool directory.
- Build tool page template.
- Create design tokens.
- Add responsive layout.
- Add metadata model.

## Phase 2: Flagship Tool

- Build typewriter invoice form.
- Build invoice calculation logic.
- Build notebook-grid invoice preview.
- Add typewriter animation.
- Add PDF export.
- Add PNG export.
- Add print styles.
- Test invoice layout across screen sizes.

## Phase 3: First Utility Set

- Build color palette generator.
- Build WCAG contrast checker.
- Build image compressor.
- Build QR code generator.
- Add shared copy/download/export controls.
- Add related tools.

## Phase 4: SEO And Polish

- Add SEO content blocks.
- Add FAQ content.
- Add Open Graph metadata.
- Add structured data.
- Add tool examples.
- Add accessibility pass.
- Add performance pass.

## Phase 5: Asset Tools

- Build favicon generator.
- Build screenshot beautifier.
- Build image format converter.
- Build image palette extractor.

## Phase 6: Advanced Tools

- Explore background remover.
- Explore raster-to-SVG converter.
- Build color blindness simulator.
- Build gradient generator.
- Build font pairing tool.
- Build CSS shadow and clip-path tools.

## Phase 7: Business Layer

- Add optional analytics.
- Add newsletter or update capture.
- Explore paid export templates.
- Explore embeddable quote calculator.
- Explore saved projects or accounts only if user demand is clear.
