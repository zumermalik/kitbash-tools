# Kitbash Scope

## Product Summary

Kitbash is a browser-first suite of creative, design-system, and utility tools. It should launch as one cohesive web app with a homepage, a tool directory, and individual tool pages.

The first version does not need AI. The product should earn trust through speed, taste, privacy, and useful exports.

## In Scope

### Suite Shell

- Homepage with hero section and tool directory.
- Shared navigation across all tool pages.
- Search/filter for tools once the catalog grows.
- Consistent tool page layout.
- Shared output panel pattern.
- Shared export/copy/download controls.

### Flagship Tool

- Typewriter invoice generator.
- Line item editor.
- Tax/discount/total calculation.
- Client and sender details.
- Invoice number and dates.
- Japanese notebook-grid inspired output page.
- Letter-by-letter typewriter animation.
- PDF export preserving the aesthetic.
- PNG export as a shareable image.

### Image/Asset Tools

- Background remover.
- Image compressor.
- Image format converter for HEIC, WebP, PNG, JPG, and AVIF where browser support allows.
- Raster-to-SVG vector converter.
- Favicon generator.
- Screenshot beautifier.
- Image color palette extractor.

### Color & Design-System Tools

- Color palette generator.
- WCAG contrast checker.
- Color blindness simulator.
- Gradient generator.
- Font pairing tool.
- CSS box-shadow generator.
- CSS clip-path generator.

### Generators & Calculators

- QR code generator.
- Price/quote calculator.
- UUID generator.
- Password generator.
- Timestamp and epoch converter.
- JSON formatter and validator.
- Meta tag and OG image previewer.

## Out Of Scope For MVP

- User accounts.
- Paid subscriptions.
- Cloud file storage.
- Team workspaces.
- AI generation.
- Server-rendered user projects.
- Marketplace templates.
- Native desktop apps.

These can be reconsidered after the core suite proves useful and searchable.

## MVP Definition

The MVP should include:

- Homepage and tool directory.
- Shared visual system.
- Typewriter invoice generator.
- Color palette generator.
- WCAG contrast checker.
- Image compressor.
- QR code generator.
- Basic SEO pages and metadata.

## Success Criteria

- A user can understand the product within the first viewport.
- A user can open a tool and produce output without signing in.
- Every MVP tool has copy/download/export behavior where relevant.
- The invoice generator feels distinctive enough to share.
- Tool pages are indexable and have clear search intent.
